# desk-clock v0.7.7 · Windows 自启「值名写错」真根因留证（2026-11-14 14:1x GMT+8）

主人反馈（第 4 次）：「昨天的桌面时钟，开机自启功能还是没有实现，重启电脑还是不会自动启动。」
上一版（v0.7.6 修订版2）已修「注册表命令没加引号」并做过真机弹窗验收，但自启仍失败。

## 一、真根因（全部有上游源码坐实，非猜测）

| # | 证据 | 源码位置 |
|---|---|---|
| 1 | 插件用 `app.package_info().name` 作为 Windows `Run` 值的**值名** | `tauri-plugin-autostart 2.7.0` `src/lib.rs:225-229`（`self.app_name.unwrap_or_else(\|\| &app.package_info().name)`） |
| 2 | `PackageInfo.name` 优先取 `tauri.conf.json` 的 `productName` | `tauri-codegen 2.7.4` `src/context.rs:250-263`（`let package_name = if let Some(product_name) = &config.product_name {...}`） |
| 3 | 本项目 `productName = "Desk Clock"`（**带空格**） | `src-tauri/tauri.conf.json:3` |
| 4 | 上游命令由 `format!("{} {}", app_path, args)` 拼出，**路径无引号** | `auto-launch 0.6.0` `src/windows.rs` `enable_with_root_key()` |

→ 值名是 `Desk Clock`，**不是** Cargo 包名 `desk-clock`。

### 为什么 v0.7.6 修了引号仍然不行

v0.7.6 的 `repair_windows_run_value()` 硬编码 `WIN_RUN_APP_NAME = "desk-clock"`，于是机器上长期**两条并存**：

- `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\Desk Clock`
  = `C:\Users\x\AppData\Local\Desk Clock\desk-clock.exe --startup`（插件写，无引号）
  → Windows 登录把它截断成 `C:\Users\x\AppData\Local\Desk`，**静默失败**
- `HKCU\...\Run\desk-clock`
  = `"C:\...\desk-clock.exe" --startup`（v0.7.6 补写，正确）

而 `is_enabled()` 只查 `package_info().name` 即 `Desk Clock` 那条 → **界面永远显示「已开启」、重启永远不启动**；且旧值永远不被清理，「一键修复」也无法替换它。
这解释了主人三次反馈的所有现象：勾上去了、诊断说正常、重启就是不起来。

## 二、v0.7.7 落地改动

Windows 自启**完全自管**，不再经过插件（macOS/Linux 保持插件）：

| 改动 | 说明 |
|---|---|
| `win_run_value_name(app)` | 值名取 `app.package_info().name`，与插件/任务管理器显示一致，不再多出一条 |
| `win_expected_run_value()` | `"<exe>" --startup`，带引号绝对路径 |
| `repair_windows_run_value(app)` | ①删历史值名（`desk-clock`/`DeskClock`）②写 HKCU（HKLM 存在则同步）③写 `StartupApproved\Run` 启用字节 `020000000000000000000000` ④`reg query` **精确回读比对**，不一致返回 Err |
| `win_autostart_healthy(app)` | 已登记 + 命令精确匹配 + 未被任务管理器禁用 |
| `win_autostart_disable(app)` | 删全部相关值（含遗留）+ 删 StartupApproved |
| `win_log_startup(app)` | 每次启动追加 `%APPDATA%\app.deskclock.desktop\startup.log`，标注 `AUTOSTART`/`MANUAL` + 完整 argv + exe，>64 KB 轮换 |
| `set_autostart` / `get_autostart` / `repair_autostart` | Windows 分支全部走自管实现；非 Windows 保留插件 |
| `.setup()` 自愈 | 由「无脑重写」改为 `if prefs.autostart && !healthy { 重写 + 校验 }` |
| 诊断面板 | 新增 `valueName` / `expectedCommand` / `legacyValues` / `healthy` / `startupLog` / `startupLogPath`；UI 渲染遗留项与最近启动记录 |
| 版本 | 0.7.6 → 0.7.7（conf / Cargo.toml / Cargo.lock / APP_VERSION / 3 处原生标题 / README / CHANGELOG / release.yml / 6 个验证脚本断言） |
| 新增回归 | `scripts/verify_v077.py` 31 项；`build.yml` 静态门禁收录 |
