Desk Clock 开机自启 · 诊断与一键修复工具（v3）
================================================

用法（三步）
------------
1. 把压缩包解压到桌面。**强烈建议把 fix-autostart.cmd 和 fix-deskclock-autostart.ps1
   直接放到 desk-clock.exe 同一个文件夹里**（比如 C:\Users\你\AppData\Local\Desk Clock\），
   这样工具能 100% 找到程序本体；找不到时它会提示你手动粘贴 exe 完整路径。
2. 双击 fix-autostart.cmd。
   脚本会自动请求管理员权限（弹 UAC 请点「是」）；已经以管理员身份运行则直接执行。
   若弹出「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。
3. 看窗口输出，然后把**桌面上的 DeskClock-autostart-report.txt** 发回给我。

它打印什么、每一项对应什么病
--------------------------
[1/7] 程序路径 + 文件版本
      → 版本不是 0.7.7 = 你装的是旧版，旧版有已知的自启 bug。

[2/7] 注册表 Run 里的原始条目（只打印与 desk-clock 相关的）
      → 「带引号: 否」= 路径有空格却没加引号，Windows 登录时把
        C:\Program Files\Desk Clock 当成程序名 → 静默跳过，必失败。
      → 「目标存在: 否」= 启动项指向的程序已被移动/删除/换目录 → 同样静默失败。

[3/7] 「启动应用已禁用」字节 + 「以管理员身份启动」标记
      → 已禁用：任务管理器里被人关过，登录直接跳过。
      → RUNASADMIN：登录时弹 UAC 无法显示 → 静默失败。

[4/7] startup.log（最关键的一行证据）
      → 有 AUTOSTART = Windows 确实在登录时拉起过程序（问题在程序自身或被杀软拦）
      → 只有 MANUAL   = Windows 从来没在登录时拉起它（问题在启动项本身）

[5/7] 修复：写入「带引号的当前 exe 绝对路径」+ 删除历史错值名 + 清禁用字节 + 去 RUNASADMIN
[6/7] 备用通道：创建「登录时」触发的计划任务 DeskClock Autostart（与 Run 键双保险）
[7/7] 自检：用与开机完全相同的命令拉起程序，确认进程真的起来

安全说明
--------
只改你自己账户的启动项与一个登录计划任务，不动系统其他配置、不联网、不上传任何数据。
撤销：时钟设置里关掉「开机自启」；或任务管理器 → 启动应用 里禁用；
计划任务可在「任务计划程序」里删除名为 DeskClock Autostart 的那一项。

如果还不行
----------
请把报告发我。另外两点请一起确认：
1）你装的是不是 v0.7.7（设置窗口标题栏右下角有版本号）；
2）火绒/360 等安全软件有没有在开机时弹过拦截或静默拦杀——如果有，
   请把 desk-clock.exe 加进白名单后再试。
